# Splunk Log Investigation

This repository contains hands-on log investigation assignments completed using **Splunk**. These exercises simulate common tasks performed by security analysts in a Security Operations Center (SOC), including firewall monitoring, incident response automation, and forensic log analysis.

## Objective

The goal of this work was to build practical experience in:

- Investigating logs across multiple sources (web servers, firewalls, Windows systems)
- Writing and optimizing Splunk search queries (SPL)
- Identifying Indicators of Compromise (IOCs) and security events
- Automating incident response using SOAR concepts
- Building SOC-style reports and visualizations

---

## Included Assignments

- `Apache Log Investigation.pdf`  
  Analysis of access and error logs to detect suspicious activity and unauthorized access patterns.

- `Firewall Log Analysis with Splunk.pdf`  
  Used Splunk to identify denied inbound/outbound traffic, potential port scans, and blocked IPs.

- `SOC Report - Firewall Log Analysis.pdf`  
  Simulated SOC-style report with incident classification, log breakdown, and response actions.

- `Windows Log Investigation.pdf`  
  Investigation of Windows Security Event Logs to detect user logon events, failures, and privilege escalation attempts.

- `SOAR Assignment - Automated Incident Response.pdf`  
  Designed and documented an automated workflow to respond to high-confidence threats using SOAR concepts.

- `Splunk Introduction - Analysis of a Log.pdf`  
  Walkthrough of basic SPL queries, log ingestion, and parsing techniques.
